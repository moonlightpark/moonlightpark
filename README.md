### 🗣️ [SpeakUp 6M](https://moonlightpark.github.io/Speakup-6months/)
**"6개월 뒤, 입으로 나오는 외국어."**

A voice-first app for Korean speakers learning English and Japanese. It follows a structured **182-day course**, with about **70% of study time spent speaking and listening**.

- 🎙️ **Offline pronunciation scoring** that grades each word and measures speaking speed
- 📅 Daily routine: review → words → reading → grammar → listening → conversation
- 🎬 YouTube shadowing with repeat loops, plus graded classic texts
- 📚 46 English grammar points (A1–C1) and 45 Japanese (N5–N1)
- 🇯🇵 Kana/kanji flashcards, furigana, and **2,211 JLPT kanji**
- 💬 6,000-word dictionary, 1,300 sentences, 400 conversation situations
- 🔒 **Fully offline:** no account, and no audio uploaded

`Whisper` `Kokoro TTS` `VOICEVOX` `lindera` `Claude API (optional)`

📱 macOS · Windows · Android tablet & phone · **MIT License, Free**

👉 **[Visit the project page →](https://moonlightpark.github.io/Speakup-6months/)**
